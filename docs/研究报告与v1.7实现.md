# 独立研究报告与 v1.7 实现

研究台原来可以导出 Markdown 摘录和 SVG 地图。本轮新增独立 HTML 报告：让接收者直接阅读问题、证据、笔记与出处，必要时跳到报告内附的原文高亮，无需打开原知识库或加载模型。

## 从高星项目学到什么

2026-11-06 阅读 [Zotero 仓库](https://github.com/zotero/zotero)（当时约 15.9k 星）、[官方报告说明](https://www.zotero.org/support/reports)及[报告生成模块](https://github.com/zotero/zotero/blob/main/chrome/content/zotero/xpcom/report.js)。参考的是把资料信息与笔记组织成可独立保存、阅读和打印的网页这一产品方式。

CiteMind 按研究问题组织摘录，保留收集时的来源名称、位置与人工判断；附原文时支持高亮核对。报告模块、页面、样式与测试均为本项目独立编写，没有复制 Zotero 的代码或引入其运行库。

## 使用与内容范围

1. 在研究笔记中点击“生成研究报告”。预览使用打开时的完整收集记录，包括笔记筛选后暂时隐藏的条目。
2. 默认只加入已收集摘录、个人笔记和引用信息。需要报告内核对完整文字时，手动勾选“附上所引资料的完整提取文字”。
3. 检查预览后下载 HTML。可以将这个文件离线打开、搜索或用浏览器打印。

加入全文时只包含被收集记录引用的当前资料，不会带上知识库里其他资料。全文可能含没有摘录的内容，选项旁和报告末尾均明确提醒检查分享范围。每次重新打开预览都恢复为不附全文。

报告是固定的阅读快照。导出后知识库更新不会自动改变报告；需要继续编辑、恢复完整知识库或迁移设备时，仍使用 JSON 备份。

## 出处与交互

- 以实际收集的问题分组，只合并空白差异。目录链接跳到对应问题，摘录按收集记录编号。
- 每条证据显示原文、人工标记、个人笔记、收集时间、分块标识和 UTF-16 位置；PDF 来源另显示真实分页元数据。
- 导出时重新检查摘录文字与来源位置。来源缺失、文字变化或 PDF 页码不符时保留原摘录并给出警示，不生成指向错误高亮的链接。
- 附全文时，每份资料只出现一次；重叠摘录合并高亮，保留各自跳转锚点，可返回相应证据。
- 全文使用当前资料名称，来源列表说明收集时名称的变化。报告正文仍保留收集时的来源名称。
- 没有自动结论、事实判断或隐含的语义连线。文字匹配状态只说明导出时的当前知识库，并非事实验证或来源身份认证。

## 独立阅读与实现边界

导出函数不依赖 DOM，验证输入后把所有标题、问题、摘录与笔记转义为文字；链接只由程序生成的本地编号构成。报告内没有脚本、事件处理器、外部字体、图片或资源请求，并通过内容安全策略限制活动内容。应用内预览放在受限的 iframe 中。

正文与样式都在同一文件内。目录、原文锚点和原生折叠区使用浏览器自带能力；内置移动布局和打印样式。附全文可能产生较长的文件，复杂 Word / PDF 排版仍以原始文件核对，不能把提取文字视作原文件版式。

## 验证范围

新增 4 项数据与导出检查：问题分组及同名来源隔离、默认范围与全文选择、恶意文字转义、重叠摘录与失效 PDF 页码。输入不能被导出过程修改，只有仍匹配的引用可获得全文锚点。

新增 3 条浏览器场景，在桌面与 390px 移动布局各运行一次，共 6 条：

- 预览默认范围、手动加入全文、下载真实 HTML 文件，关闭网络后从本地文件打开并跳到正确高亮；没有 HTTP 请求或横向溢出。
- 恶意标题和笔记显示为文字，失效引用保留警示，错误页码没有定位链接。
- 准备完整离线包后断网重载，生成报告、修改批注后重新生成，确认内容更新且全文选项恢复关闭。

还目视检查了独立报告、手机阅读和应用内手机预览，调整布局使下载按钮持续可见。浏览器打印样式已提供，但没有据此声称验证了所有打印机或 PDF 分页效果。手机场景是桌面 Chrome 视口模拟，尚非真实手机验证。
