- 网页：https://xf-png.github.io/citemind/
- 源码：https://github.com/xf-png/citemind

网站已公开发布，访客无需登录 GitHub 或安装插件。v1.2 将 AI 模型、运行组件与 PDF 组件一起托管到本站，首次启用不再访问 Hugging Face 或 jsDelivr。旧版 PDF 手册于 10 月 18 日制作，其中“公开入口待验证”和外部资源依赖描述的是 v1.1 的状态；当前访问地址与加载方式以本文为准。

## 直接体验

1. 打开上方网页，使用内置的五份示例资料。
2. 输入“如何避免 AI 编造答案？”，发送后查看回答与来源。
3. 点击来源卡片，核对高亮原文；也可以导入自己的 TXT、Markdown 或文字层 PDF。
4. 在“保存与备份”开启浏览器本地保存，或导出知识库备份。
5. 点击右上角“快速检索”，可选择本地 AI 语义检索。首次从本站下载约 47 MB 模型与运行组件，其中模型权重约 24 MB；之后可复用浏览器缓存。

快速检索加载网站文件后即可处理资料；PDF 与 AI 按需从当前网站加载。AI 加载较慢或失败时，仍可使用快速检索处理文本。当前回答为原文摘录，不包含生成式大语言模型。此版本没有离线应用缓存，不承诺断网后重新打开网页可用。

## 已完成的发布验证

- 检索与存储检查共 24 项通过；发布工作流会先检查功能与全部第三方资源的完整性，再部署完整 dist。
- 模型和 PDF 资源共 211 个、约 52.24 MB，均保留官方来源、字节数与 SHA-256 清单，随站点公开分发并保留许可。
- 首页与顶层九个网站文件通过访问及内容验证；v1.2 发布后再逐项验证同源第三方资源。
- JavaScript 文件的响应类型适合 ES Modules 加载，资源和 Worker 路径使用相对路径，适用于 `/citemind/` 子目录。
- 下载并执行线上 engine.js，示例问题命中“检索与引用策略”，摘录与原文位置一致；无关足球比分问题返回零条来源。

PDF 改动已通过使用实际解析器的 Node 辅助验证，覆盖空白页、中文 CMap 和字体加载及加密文件拒绝。本轮没有重新进行浏览器完整交互或首次模型下载测试；此前本地浏览器验证覆盖资料保存、PDF 页码引用和真实模型推理。这些检查不能保证所有访问者的设备和网络情况。访客资料在自己的浏览器处理，不会发布到 GitHub 仓库。

## 更新网站

项目 main 分支更新后，GitHub Actions 自动运行检查并将 dist 目录发布到同一个地址。可在仓库 Actions 页查看进度。无须重新安装 Codex GitHub 插件。

账号授权通过 GitHub 官方 CLI 完成，凭据保存在系统凭据库中；仓库和发布包不包含账号密码或访问令牌。
