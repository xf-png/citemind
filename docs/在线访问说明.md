## 直接体验

1. 打开上方网页，使用内置的五份示例资料。
2. 输入“如何避免 AI 编造答案？”，发送后查看回答与来源。
3. 点击来源卡片，核对高亮原文；也可以导入自己的 TXT、Markdown 或文字层 PDF。
4. 在“保存与备份”开启浏览器本地保存，或导出知识库备份。
5. 点击右上角“快速检索”，可选择本地 AI 语义检索。首次启用需要下载约 24 MB 模型权重及额外运行组件。

快速检索加载网站文件后即可处理资料；PDF 解析依赖 jsDelivr，本地 AI 首次加载还依赖 Hugging Face。某个外部资源下载失败时，仍可使用快速检索处理文本。当前回答为原文摘录，不包含生成式大语言模型。

## 已完成的发布验证

- GitHub Actions 中的检索与存储检查共 24 项通过，Pages 发布步骤成功。
- 公开首页与九个网站文件均返回 HTTP 200，逐个比对 SHA-256，内容与提交文件一致。
- JavaScript 文件的响应类型适合 ES Modules 加载，资源和 Worker 路径使用相对路径，适用于 `/citemind/` 子目录。
- 下载并执行线上 engine.js，示例问题命中“检索与引用策略”，摘录与原文位置一致；无关足球比分问题返回零条来源。

本轮没有重新进行浏览器完整交互或首次模型下载测试。此前本地浏览器验证覆盖资料保存、PDF 页码引用和真实模型推理；这些检查不能保证所有访问者的网络均能下载外部组件。访客资料在自己的浏览器处理，不会发布到 GitHub 仓库。
