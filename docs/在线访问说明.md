## 直接体验

1. 打开上方网页，使用内置的五份示例资料。
2. 输入“如何避免 AI 编造答案？”，发送后查看回答与来源。
3. 点击来源卡片，核对高亮原文；也可以导入自己的 TXT、Markdown、Word DOCX 或文字层 PDF。
4. 在“保存与备份”开启浏览器本地保存，或导出知识库备份。
5. 点击右上角“快速检索”，可选择本地 AI 语义检索。首次从本站下载约 47 MB 模型与运行组件，其中模型权重约 24 MB；之后可复用浏览器缓存。
6. 收集证据并在研究台写批注；“生成研究报告”可导出独立阅读的 HTML，附上全文需手动选择。

快速检索加载网站文件后即可处理资料；PDF 与 AI 按需从当前网站加载。AI 加载较慢或失败时，仍可使用快速检索处理文本。当前回答为原文摘录，不包含生成式大语言模型。v1.2 没有离线应用缓存；v1.4 可在“保存与备份”主动准备完整离线包，确认就绪后断网重开。

## 更新网站

项目 main 分支更新后，GitHub Actions 自动运行检查并将 dist 目录发布到同一个地址。可在仓库 Actions 页查看进度。无须重新安装 Codex GitHub 插件。

本地推送使用系统凭据管理器中已有的账号授权。仓库和发布包不包含账号密码或访问令牌。
